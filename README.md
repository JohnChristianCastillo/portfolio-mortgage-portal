# Mortgage Borrower Portal

Minimal borrower portal: mortgage simulation, sign-up, a multi-step mortgage
application, and document upload linked to that application.

Status: work in progress, scaffolding stage.

## Stack

- Backend: FastAPI (Python), object-oriented service/repository layers
- Frontend: Angular
- Persistence: SQLite
